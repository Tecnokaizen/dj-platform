# Rules

- Read AGENTS.md first.
- Read PROJECT_CONTEXT.md.
- Read docs/INDEX.md.
- Read the task before coding.
- Never use `any`.
- Never access Prisma outside repositories.
- Never use `process.env` outside `src/lib/env`.
- Justify every new dependency.
- Do not change architecture without approval.
- Run:
  - npm run lint
  - npm run typecheck
  - npm run build
before marking a task complete.
