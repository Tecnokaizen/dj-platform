# Maintenance Operations

## Purpose

This document defines routine operational maintenance.

Maintenance preserves platform reliability over time.

---

# Philosophy

Preventive maintenance is preferable to reactive maintenance.

Small improvements prevent large failures.

---

# Maintenance Areas

Routine maintenance includes:

- dependency updates
- operating system updates
- database optimization
- log cleanup
- storage review
- certificate renewal
- security review
- documentation review

---

# Maintenance Schedule

Maintenance activities should be scheduled.

Emergency work should remain exceptional.

---

# Validation

Every maintenance task should conclude with verification.

No maintenance is complete until platform health is confirmed.

---

# Documentation

Maintenance activities should be recorded.

Significant changes require updated documentation.

---

# Continuous Improvement

Maintenance should improve:

- reliability
- security
- performance
- operational simplicity

---

# AI Development Rules

AI coding agents must document maintenance-related changes.

---

# Final Principle

Reliable platforms are maintained continuously, not repaired occasionally.
